# The Night Game

Juego de equipos para jugar con un solo móvil, en tres rondas con el mismo mazo:

1. **Descripción libre**: se puede hablar, sin decir la palabra.
2. **Una sola palabra**: una pista y un único intento.
3. **Mímica**: sin hablar.

Incluye seis categorías de 200 cartas (Personajes famosos, Cine, Música, Fútbol, Videojuegos y XCEED), cartas propias, temporizador, marcador por equipos, modo claro/oscuro y español/inglés.

## Cómo funciona

Es una web estática de un solo archivo: `index.html`. No necesita instalación ni paso de compilación. La partida en curso se guarda en el navegador de cada jugador.

## Probarlo en local

Abre `index.html` en el navegador.
